# Bash Shell Scripting & Linux Fundamentals 🖥️🐧

Welcome to the **Bash Shell** repository completed at **Holberton School**. This repository features shell scripts, command-line utilities, file permissions management, input/output redirections, and environmental variable configurations in a Linux environment.

---

## 📌 Modules & Core Concepts

| Directory / Topic | Description & Core Concepts |
| :--- | :--- |
| `basics` | Introduction to shell scripting, basic commands, and syntax |
| `init_files_variables_and_expansions` | Aliases, shell variables, expansions, and startup files |
| `io_redirections_and_filters` | Standard streams (`stdin`, `stdout`, `stderr`), pipes, and filters (`grep`, `awk`, `sed`) |
| `permissions` | Managing Linux file permissions, `chmod`, `chown`, and user/group access |

---

## 🛠️ Environment & Tools

- **Shell:** Bash (GNU Bourne-Again SHell)
- **OS Environment:** Ubuntu / Linux WSL2
- **Execution Standards:** Shebang `#!/bin/bash` with executable permissions (`chmod +x`)

---

## 🚀 How to Run Scripts

To execute any shell script:

```bash
# Ensure execution permissions:
chmod +x path/to/script.sh

# Run the script:
./path/to/script.sh
